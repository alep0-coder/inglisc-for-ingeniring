# Engineering English - Web Version

Questa è la versione web dell'app pronta per essere caricata su GitHub.

## Come usarla per i tuoi amici (iPhone/Browser):

1. **Crea un nuovo Repository su GitHub**: Chiamalo come preferisci (es. `engineering-english`).
2. **Carica i file**: Carica tutto il contenuto di questa cartella (`web-deploy`) nel repository.
3. **Attiva GitHub Pages**:
   - Vai nelle **Settings** del repository su GitHub.
   - Clicca su **Pages** nel menu a sinistra.
   - Sotto "Build and deployment", seleziona **Deploy from a branch**.
   - Scegli il branch `main` (o quello che hai usato) e la cartella `/ (root)`.
   - Clicca su **Save**.
4. **Condividi il link**: Dopo qualche minuto, GitHub ti darà un link (tipo `https://tuo-nome.github.io/engineering-english/`). Condividi questo link con i tuoi amici!

## Funzionalità PWA
L'app è configurata come **PWA (Progressive Web App)**. I tuoi amici su iPhone possono:
- Aprire il link in Safari.
- Cliccare sull'icona **Condividi** (il quadrato con la freccia in alto).
- Selezionare **"Aggiungi alla schermata Home"**.
- L'app apparirà come un'app normale sul loro telefono!
