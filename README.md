# Engineering English App - v1.0

Benvenuto nella prima versione ufficiale dell'app **Engineering English**!

Questa applicazione è progettata per aiutarti a studiare i termini tecnici del libro *Professional English in Use Engineering*.

## 🚀 Come avviare l'app

1. Assicurati di essere nella cartella `web/`.
2. Esegui `npm install` se è la prima volta.
3. Esegui `npm run dev` per avviare il server di sviluppo.
4. Apri l'indirizzo mostrato nel terminale (solitamente `http://localhost:5173`).

## 📚 Funzionalità principali

- **35 Unità**: Contenuto estratto fedelmente dal libro (Unità 1-21, 23-29, 37-39, 42-45).
- **Interfaccia "Click-to-Match"**: Esercizi di collegamento interattivi e dinamici.
- **Revision Hub**: Una sezione dedicata dove puoi leggere tutta la teoria in un'unica pagina, ideale per il ripasso pre-esame.
- **Teoria Integrata**: Ogni lezione ha la sua spiegazione accessibile tramite l'icona 📖.
- **Progressi**: I tuoi progressi vengono salvati automaticamente nel browser.

## 🛠️ Manutenzione del Database

Se desideri modificare o aggiungere nuovi contenuti:
1. Modifica i file JSON nella cartella `scratch/`.
2. Esegui `node scratch/merge_db.js` dalla cartella principale per aggiornare il database globale.
